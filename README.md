# Scraper d’offres de stage

Projet personnel visant à automatiser ma recherche de stage grâce à un outil capable de collecter, filtrer et classer des offres selon plusieurs critères clés.

## Objectif

La recherche de stage peut rapidement devenir chronophage lorsque les offres sont réparties entre de nombreux sites carrières et plateformes.

L’objectif de ce projet est donc de développer un scraper permettant de :

- centraliser automatiquement les nouvelles offres ;
- éliminer les annonces qui ne correspondent pas à mes critères ;
- identifier rapidement les opportunités les plus pertinentes ;
- réduire le temps consacré à la recherche manuelle ;
- pouvoir candidater rapidement après la publication d’une offre.

## Fonctionnement

Le programme récupère les informations principales de chaque annonce, telles que :

- intitulé du poste ;
- entreprise ;
- localisation ;
- date de publication ;
- date de début du stage lorsqu’elle est disponible ;
- lien vers l’annonce ;
- informations utiles à l’évaluation de la pertinence de l’offre.

Les offres sont ensuite filtrées et classées selon différents critères afin de faire ressortir les opportunités prioritaires.

## Critères de sélection

Le système peut notamment prendre en compte :

- la récence de l’annonce ;
- la localisation ;
- la date de début du stage ;
- le type de poste ;
- la cohérence avec le profil recherché ;
- différents mots-clés présents dans le titre ou la description.

## Technologies utilisées

- Python
- Web scraping
- Traitement et filtrage de données
- Automatisation
- Git / GitHub

## Évolutions envisagées

Plusieurs améliorations pourront être ajoutées progressivement :

- ajout de nouvelles sources et sites carrières ;
- détection automatique des nouvelles annonces ;
- suppression des doublons ;
- système de scoring des offres ;
- classement par pertinence ;
- notifications lors de la publication d’une nouvelle offre ;
- dashboard permettant de visualiser et suivre les opportunités ;
- historique des offres et des candidatures.

## Finalité du projet

Au-delà de son utilisation pour ma propre recherche de stage, ce projet me permet de mettre en pratique des compétences en programmation, automatisation, traitement de données et conception d’outils répondant à un besoin concret.
